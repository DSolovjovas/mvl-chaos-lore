# Miu — основной образ

Чёрный короткий топ с корсетной конструкцией, розовой отделкой и шнуровкой; короткая многослойная чёрная юбка с розовыми деталями; чёрные чулки, бантики и подвязки; обувь на платформе; чёрный чокер с фиолетовым колокольчиком. Силуэт и детали сверять с листом.

## Не должно быть

Смешения одежды других персонажей; произвольной замены канонического образа. Для Vexa не использовать карго/тактическую форму вместо шорт. Дополнительные ограничения — в базе.
