# Визуальные референсы

Сюда добавляются утверждённые изображения Miu, Vexa, Lumi и Bruno.
Пока изображения не загружены; старые или неподтверждённые варианты автоматически не подставляются.

Для каждого изображения сохраняйте имя персонажа, назначение (лицо, основной образ, костюм, реквизит), статус утверждения и происхождение. Личные фотографии и чужие материалы не добавляются автоматически.
