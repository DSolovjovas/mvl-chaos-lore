# Same Girls. Different Chaos.

Private lore archive for Miu, Vexa, Lumi, and Bruno: character stories, worldbuilding, annotated canon, and visual references.

## Читать

Скачайте репозиторий и откройте `reader/index.html` в браузере. Интернет и установка пакетов для чтения не нужны.

- **История** — связный рассказ, девять глав и цветные реплики с именами персонажей.
- **Канон и мир** — полный авторский справочник: факты, объяснения, хронология и открытые вопросы.
- **Референсы** — основные листы и лица четырёх персонажей, краткие описания, характеры, мотивы и правила. Оригинальные восемь изображений сохранены без перерисовки, с проверкой SHA-256. Хэллоуинские костюмы ожидают утверждённых файлов пользователя.

Есть поиск по текущему тексту, светлая и тёмная темы, настройка размера шрифта. Настройки сохраняются только в вашем браузере. Внешние шрифты, аналитика и сетевые библиотеки не используются.

Цвета реплик: Миу — розовый, Векса — зелёный, Луми — голубой. Имена и цветные линии сохраняют понятность без опоры только на цвет. Общие реплики девушек, у которых ещё не выбран конкретный говорящий, подписаны «Девушки».

## Пополнять

Основные редактируемые документы:

- `История персонажей.md` — художественная история.
- `Канон и объяснения.md` — факты и объяснения. Непринятые идеи должны оставаться явно помеченными.
- `Правила референсов.md` — постоянные правила визуального канона и использования изображений.
- `reader/content/characters.json` — профили, роли изображений, источники и контрольные суммы.

После изменения документов запустите из корня репозитория:

```text
python build_reader.py
```

Нужен Python 3.12 или новее, сторонние пакеты не требуются. Сборка переносит актуальные тексты в `reader/content/` и обновляет страницы. При изменении существующего файла предыдущая версия сохраняется локально в `Корзина/reader/` с проверкой содержимого. Эти копии не отправляются в GitHub.

Имена говорящих заданы в `reader/content/dialogue.json`: каждая реплика соответствует своему персонажу. При добавлении или изменении диалогов обновляйте этот файл в том же порядке. Несовпадение останавливает сборку, чтобы не присвоить реплику другому персонажу.

Стили находятся в `reader/assets/reader.css`. Главы оформленной истории задаются в `build_reader.py`; текст в процессе оформления не переписывается.

Изображения находятся в `reader/references/`. Новые костюмные референсы добавляются туда и в профиль соответствующего персонажа с указанием назначения и статуса утверждения. Не подставляйте неподтверждённые генерации вместо референсов. Исторические записи в подпапках `sources/` сохраняют происхождение: новые прямые уточнения пользователя и текущий канон имеют приоритет. `prepare_references.py` — разовый импорт из прежнего локального архива, не обязательная команда для других компьютеров.

## Приватность

Материал непубличный, содержит взрослые темы. Репозиторий должен оставаться приватным. Публичный сайт и GitHub Pages не настроены. `noindex` на страницах не является защитой доступа; приватность обеспечивает хранение локально или доступ к приватному репозиторию. Для размещения сайта потребуется отдельное решение об авторизации и доступе.
