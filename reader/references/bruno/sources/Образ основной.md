# Bruno — основной образ

Толстый чёрный ошейник с металлическими деталями и ровно один зелёный жетон/подвеска в форме авокадо. Без другой одежды. Красная бабочка допустима только по явной просьбе для праздничной сцены.

## Не должно быть

Смешения одежды других персонажей; произвольной замены канонического образа. Для Vexa не использовать карго/тактическую форму вместо шорт. Дополнительные ограничения — в базе.
