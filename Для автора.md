# MVL CHAOS — материалы автора и ассистента

Этот файл — точка входа в актуальные материалы проекта. Его ссылку можно дать ассистенту с просьбой прочитать связанные документы перед работой. Ссылка предоставляет контекст; обновления нужно перечитывать при следующем обращении к проекту.

## Что читать

1. [Канон и объяснения](Канон%20и%20объяснения.md) — все установленные факты, их смысл, хронология и сохранённые тайны.
2. [История персонажей](История%20персонажей.md) — текущая художественная редакция.
3. [Правила референсов](Правила%20референсов.md) — внешность, приоритеты и правила генерации.
4. [Полные профили и реестр изображений](reader/content/characters.json) — роли, происхождение, контрольные суммы, авторские описания и зрительские поля public.
5. [Правила работы с проектом](AGENTS.md) — сохранение версий и публикация.

## Как устроен зрительский сайт

Страница «Персонажи» показывает краткие описания из public и только изображения с show_on_site=true. Полные поля character, motive, rules, halloween, source и sha256 предназначены для авторской работы и не выводятся автоматически. Не включать служебные инструкции обратно в зрительскую страницу.

При будущем разрешённом показе костюмов согласованно обновить разрешение и сайт. Одна лишь загрузка изображения в GitHub не означает разрешение показать его зрителю.
